## 已验证的核心链路

```text
when-e2e-test TCP gRPC Client
  -> 独立 when-app Server（health=SERVING）
  -> ETCD node/worker Lease 注册与保活
  -> Submit
  -> Redis 保存 PENDING
  -> Query 返回 PENDING
  -> Netty 时间轮到期
  -> LogOnlyDueMessageHandler
  -> Server 日志 event=when_due（仅消息标识，不调用下游 Sink）
```

到期处理器先将消息从 `PENDING` 原子 claim 为 `DELIVERING`，再写入安全日志；它不调用 HTTP/Kafka，也不将日志事件误记为 `DELIVERED`。
